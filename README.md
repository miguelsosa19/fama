# FAMA

Página de contacto de Administración FAMA en Padre Hurtado.

Dominio previsto: `admfama.cl`.

## Cloudflare Pages con GitHub

Conectar este repositorio desde Workers & Pages y crear un proyecto de Pages.
Seleccionar la rama `main`, sin framework ni comando de compilación.
El directorio de salida es `public`.

Después del primer despliegue, agregar `admfama.cl` en Custom domains y completar la validación DNS indicada por Cloudflare.
